#  Terms Of Reference - with GPT

Telegram-бот для сбора требований к IT-продукту и подготовки на их основе технического задания (ТЗ) с помощью языковой модели.

## Технологии

- **Python 3.11+** — язык проекта
- **aiogram 3** — Telegram Bot API и обработка сообщений
- **Pydantic Settings** — настройки приложения из переменных окружения
- **OpenAI-compatible API** — интеграция с языковой моделью

## Как пользоваться

1. Откройте бота в Telegram по ссылке, предоставленной его владельцем, и нажмите **Start**.
2. Ответьте на вопросы о проекте: его названии, назначении, аудитории и основных функциях.
3. Проверьте собранные ответы и следуйте подсказкам бота.
4. После завершения диалога получите подготовленное техническое задание.

*Сейчас проект находится на этапе начальной разработки: сценарий диалога и генерация ТЗ ещё не реализованы.*
